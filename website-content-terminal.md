### How to add content to existing WordPress pages:

1. **Log into WordPress admin** at tradingventureclub.com/wp-admin
2. Go to **Pages** in the left sidebar
3. Click **Edit** on the page you want to modify (Home or Services)
4. Your site uses **Elementor** or the default **WordPress Block Editor** — either way:
   - Add a new **Section** where you want the terminal content
   - Copy the text from this document
   - Style it to match your existing design (dark background, purple accents, Astra theme)
5. **Save / Update** the page

### How to add the Terminal section on Home page:

- Best placement: **after the "What You'll Learn" 6-card section** and **before the testimonials**
- Use the same card layout style as "What You'll Learn" (dark cards, numbered or with icons)
- Add a section divider with the heading "PROFESSIONAL TOOLS" / "PROFESJONALNE NARZEDZIA"
- The CTA button should link to: `https://tradingventureclub.com/terminal/`

### How to update the Services page:

- Add the Terminal section **after the existing Psychology Mentoring section**
- Use a full-width layout with alternating text/feature blocks
- Keep the same dark theme styling
- The CTA button should link to a contact form or email (mal@tradingventureclub.com)

### How to add Polish language support:

**Recommended plugin: TranslatePress (free version)**

1. In WordPress admin, go to **Plugins → Add New**
2. Search for **"TranslatePress"**
3. Install and activate it
4. Go to **Settings → TranslatePress**
5. Set **Default Language** = English
6. Add **Translation Language** = Polish (Polski)
7. Under **General → Language Switcher**, choose where to show the flag/language toggle:
   - "Floating language selection" = small flag button in corner (easiest)
   - Or add to menu: go to **Appearance → Menus**, add the "Language Switcher" item
8. **Save settings**
9. Now go to your site and click the **"Translate Page"** button in the WordPress admin bar
10. Click on any text element → paste the Polish translation from this document
11. Repeat for all sections on Home and Services pages

**Alternative: WPML** (paid, more features) or **Polylang** (free, but requires duplicate pages)

TranslatePress is the simplest — you translate directly on the live page by clicking on text elements. No duplicate pages needed.

### Language toggle in navigation:

TranslatePress automatically adds a language switcher. You can configure it as:
- A floating button (bottom-right corner) with flag icons
- A menu item in your main navigation bar
- Both

Recommended: Add it to the main menu bar next to "Terminal" for visibility.
